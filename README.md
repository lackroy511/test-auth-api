# Auth API
Сервис аутентификации и авторизации.

## Стек
- **Python 3.14** / **FastAPI** / **SQLAlchemy 2.0** async
- **PostgreSQL** / **Redis** / **Alembic**
- **Docker** / **pytest**

## Сущности
- **User** - пользователь email, имя, пароль, активность
- **Role** - роль название, описание, системная/нет
- **UserRole** - связь пользователя и роли
- **TokenVersion** - версия токенов пользователя для logout-all
- **UserAuthHistory** - история входов

## Бизнес-правила

### Аутентификация
- Регистрация - email + пароль хэшируется argon2, подтверждение пароля через дублирование
- Вход - проверка email и пароля, после успеха выдаётся пара JWT-токенов в httpOnly cookies
- **Access-токен** - короткоживущий по умолчанию 5 минут, хранится в cookie `access_token`
- **Refresh-токен** - долгоживущий по умолчанию 30 дней, хранится в cookie `refresh_token`
- Обновление токенов - по refresh-токену выдаётся новая пара, старая блокируется вблеклист
- Выход - текущая пара токенов блокируется в блеклист и удаляется из cookies

### Управление сессиями
- `logout-all` - увеличивает версию токенов пользователя, все выпущенные ранее токены становятся недействительными
- При `logout` и `refresh` токены помещаются в Redis blacklist до истечения их срока жизни
- Версия токенов кешируется в Redis для быстрой проверки без обращения к БД

### Роли и доступ
- Три предустановленные роли: `superuser`, `staff`, `subscriber` создаются при старте
- Роли, помеченные как `is_system`, нельзя удалить или изменить
- Управление ролями создание, удаление, назначение пользователям доступно только `superuser`
- Обычные пользователи не имеют доступа к эндпоинтам управления ролями

### Профиль пользователя
- Смена email или пароля - требуется подтверждение текущего пароля
- История входов сохраняется и доступна пользователю последние 10 записей

## Запуск
- Создать .env по примеру .env.example
- Запустить: `docker compose up -d`

## Запуск для разработки в devcontainer VS Code
- Создать .env по примеру .env.example
- Для работы с git из дев контейнера создать .ssh в корне и положить ключи связанные с github
- Нажать `F1` -> `Reopen in container`

## Тесты
```bash
docker compose -f src_auth/tests/functional/docker-compose.yml \
    run --build --rm auth_api_run_tests \
&& docker compose -f src_auth/tests/functional/docker-compose.yml \
    down
```
